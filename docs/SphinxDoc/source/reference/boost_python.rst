Compiled core API
=================

``liblibra_core`` is the Boost.Python extension that exposes Libra's C++
mathematics, molecular objects, Hamiltonians, dynamics, integrators, solvers,
sampling methods, and utilities to Python.

.. important::

   This page reflects the extension available in the active build environment.
   Rebuild Libra before rebuilding the documentation after changing C++ export
   declarations.
