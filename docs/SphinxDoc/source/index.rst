Libra
=====

**Open-source methods and workflows for quantum and classical dynamics.**

Libra combines a high-performance C++ core with a broad Python toolkit for
nonadiabatic dynamics, model Hamiltonians, electronic-structure interfaces,
analysis, and reproducible simulation workflows.
